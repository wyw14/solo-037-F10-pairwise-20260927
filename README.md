# WaveLab

WaveLab is a local HTTP service for tow-tank experiments. The original equipment and interlock pages expose a fixed commissioning diagnostic scenario. Operator measurements are a separate live data path.

Set `WAVELAB_DATA_DIR` to choose the archive directory (default `data/wavelab`). `POST /api/measured-runs` accepts `name`, `model_name`, `section`, and `carriage`. `POST /api/measured-runs/{id}/evidence` accepts `frame_id`, `kind` (`wave_time` or `force`), `source_id`, finite `value`, and `recorded_at` in RFC3339 form. `POST /api/measured-runs/{id}/evidence/batch` accepts `{"frames": [...]}` (up to 500) and commits the accepted frames in a single write. `GET /api/measured-runs`, `GET /api/measured-runs/{id}`, and `GET /api/measured-runs/{id}/analysis` return the supplied records and wave/force summary. Measurements are committed to `operator-measurements.json` before they are published in memory, and are reloaded when the service restarts. The archive does not automatically grant a safety permit or drive hardware.

`frame_id` is the client-generated idempotency key for one reading. A retransmitted frame whose payload matches the stored one is reported as `duplicate`; the same key carrying a different reading is a `conflict` (HTTP 409 on the single-frame endpoint) and the response names the stored frame it clashes with. Invalid frames inside a batch come back as `rejected` with a reason and never block the valid frames. Frames without a `frame_id` are always appended.

The operations page (`/operations`) is an offline-capable entry console. Readings are staged in the browser per run and probe, so a dropped field connection loses nothing; once the connection returns the queue is uploaded in confirmed batches of 20. A reconciliation view compares the server's committed frames against the local queue, auto-confirming frames the server already holds and flagging anomalies. The fixed diagnostic drill scenario is shown separately and labelled as drill data (`origin: diagnostic`), distinct from operator measurements (`origin: measured`).

The `internal/probe`, `internal/force`, `internal/permit`, `internal/carriage`, `internal/track`, `internal/wave`, `internal/absorber`, and `internal/journal` packages provide component logic for further work. Their diagnostic use does not imply that the original HTTP pages accept real sensor streams.
